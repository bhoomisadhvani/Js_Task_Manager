# 🚀 JS Task Manager

A simple and modern task management app built with **JavaScript** to organize and manage daily tasks efficiently.

## ✨ Features
- 📝 Add and manage tasks
- 📅 Set task descriptions and due dates
- 🎯 Assign task priorities
- ⚡ Simple and user-friendly interface

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript

## 💻 Getting Started
1. Clone the repository:

2.  git clone https://github.com/bhoomisadhvani/Js_Task_Manager.git
  
3. Open index.html in your browser.
